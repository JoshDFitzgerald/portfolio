      Make a list

      The robot starts with a list of 2,060 five-letter words. Any of them could be the secret word.

      2

      Cross out

      After each guess, it checks every word on the list. If a word doesn't match the colors, it gets crossed out.

      3

      Ask a smart question

      It picks the guess that splits the leftover words into the most groups. That's like asking "Is it an animal?" in 20 Questions.

      The real idea, written as code

      // Step 2: cross out words that don't fit
for (word of possibleWords) {
  if (colorsFor(guess, word) == colorsWeGot) {
    keep(word)
  } else {
    crossOut(word)
  }
}

      How good is the robot?

      I tested it on every word in its list. It never needed more than 5 guesses, and it averaged 3.4.
